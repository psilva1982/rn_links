# 📱 App Description:

![screenshot](screenshot.png)

A mobile app built with **React Native** that helps you organize your favorite links effortlessly. With this app, you can:

- Save links: Add links with custom names and organize them into categories.
- Manage your links: View links by category, edit, or delete them whenever needed.
- Quick access: Open any link directly in your phone's browser with a single tap.
- Local storage: All links are stored on your device for fast, offline access using React Native Async Storage.


A simple and practical solution to keep your links organized and always accessible!
